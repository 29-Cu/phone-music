# 网易云音源(自用)

> **只供自用。** 这个音源用的是**你自己的**网易云账号:带着你的登录去取你本来就有权限播放的歌。会员专享的歌需要你的账号本身有会员;没有会员时只能放免费的歌。
> 下载下来的音频只存在你自己服务器的私有缓存里,只给你自己的播放端放。**不要把缓存的音频公开、分享、上传或转发给任何人**,也不要把缓存目录放进网站目录或代码仓库。

## 先说清楚:你需要自己跑一个接口服务

本项目**不包含**任何网易云接口的加密或签名代码,也**不附带**接口服务。网易云这个音源只会往你配置的地址(`NETEASE_API`)发普通的 HTTP 请求,那个地址上要跑一个兼容 NeteaseCloudMusicApi 的服务。

- NeteaseCloudMusicApi 是第三方项目。它原来的代码仓库在 2023 年应网易方面的要求下线了,npm 上的包目前还在,也有一些兼容它接口的分支。
- 用不用、用哪个、以及由此产生的后果,**由你自己判断和负责**。本项目和它们没有关系。
- 用到的接口:`/cloudsearch`、`/song/url/v1`、`/song/detail`、`/login/status`、`/user/playlist`、`/playlist/track/all`。

不管用哪个,都只让它监听本机或内网,**不要**暴露到公网。

## 登录 cookie

服务端需要你网易云登录后的 cookie(关键是 `MUSIC_U`)。最省事的办法和 QQ 音乐一样,用一个带远程调试的浏览器:

```sh
google-chrome --remote-debugging-port=9222 --user-data-dir="$HOME/.config/phone-music-chrome"
```

在这个浏览器里打开 <https://music.163.com/> 登录,然后在项目目录下运行:

```sh
node tools/qq-login.js --site netease        # 写到 data/netease/cookie.txt 和 meta.json
```

- 只读 `*.music.163.com` 的 cookie;屏幕上只打印名字,不打印值。
- 设了 `NETEASE_COOKIE_FILE` 时写到那个文件;也可以用 `--out 目录` 指定。
- 浏览器里没登录(找不到 `MUSIC_U`)时不覆盖原来的文件,退出码 2。

也可以手动:在登录了的浏览器开发者工具里找到 `MUSIC_U` 的值,写进 cookie 文件(写成 `MUSIC_U=...`,或者只写值也行),并 `chmod 600`。**这个值等于你的登录,别给任何人看。**

定时刷新(路径换成你自己的):

```cron
0 */6 * * * cd /path/to/phone-music && /usr/bin/node tools/qq-login.js --site netease --cdp http://127.0.0.1:9222 >> data/netease/login.log 2>&1
```

cookie 每次用到都会重新读文件,更新后**不用重启服务**。它放在 POST 请求体里发给你的接口服务,不会出现在网址或访问日志里。

## 服务端读的环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `NETEASE_API` | (无) | 你的接口服务地址,例如 `http://127.0.0.1:3000`;不设就不开网易云 |
| `NETEASE_COOKIE_FILE` | `./data/netease/cookie.txt` | 登录 cookie;`meta.json` 放在同一目录 |
| `NETEASE_CACHE_DIR` | `./data/netease/cache` | 下载下来的音频和 `index.json`,默认上限 2GB |
| `NETEASE_CACHE_MAX_MB` | `2048` | 缓存上限,超了按「最久没放」先删 |

相对路径按项目目录算。

## 海外服务器常见的 -460

从海外或机房的 IP 访问时,网易云经常回 `-460`「网络环境存在风险」。这**不是登录问题**,重新登录没用。遇到时工具会回一句「网易云拦了这台服务器的网络(-460)……」。

通常的解决办法是把接口服务放到国内的家用网络上跑(再通过你自己的内网/隧道让服务端连过去),或者这时先用 QQ 音乐音源。

## 音质、试听片段和换版本

- 音质先要 320k(`exhigh`),拿不到完整的再要标准音质(`standard`)。
- 只给 30 秒试听片段(`freeTrialInfo` 不为空)或者没有链接,都当作「这一版放不了」:搜索时试下一条结果;放歌单时按歌名 + 歌手 + 时长找同一首的别的版本(规则和 QQ 音乐一样保守,对不上宁可不放)。

## 登录过期了会怎样

- 工具会回一句「网易云登录过期了……重新登录,再跑一次 `node tools/qq-login.js --site netease`」,AI 会转告你。
- 已经缓存过的歌照样能放。
- 处理:在那个浏览器里重新登录 → 跑一次登录工具(或等定时任务)。不用重启。

## 缓存

和 QQ 音乐一样:目录 700、文件 600,超上限按最久没放的先删;放歌单时第一首当场下,第 i 首开始放时预下第 i+1 首。`data/` 已经在 `.gitignore` 里,**不要**提交、公开或转发缓存的音频。
